# Mask Picker — гарячі клавіші та функції

Те саме коротко є в самій програмі: кнопка **?** угорі або клавіша **?**.
Детальні інструкції — `README.md` (§«✋ Ручна розмітка»).

## Головний екран (список фото і картки варіантів)

| Клавіша / дія | Що робить |
|---|---|
| **←** / **→** | Попереднє / наступне фото |
| **1** … **9** | Обрати варіант маски №N (картку) |
| **S** або **Пробіл** | Пропустити фото |
| **Shift+U** | Скинути все по фото (Hard Reset) |
| **C** | Відкрити редактор: Cleanup (обраного варіанта) |
| **P** | Відкрити редактор: Polygons |
| **Z** | Порівняти всі варіанти у великому вікні |
| **O** (тримати) | Показати оригінал замість усіх варіантів |
| **?** | Довідка |
| **Esc** | Закрити вікно |
| ☐ на картці | Обрати варіант (☑ — обрано; ще клік — скасувати) |
| ✏️ / 🧹 / 🔗 на картці | Відкрити редактор на вкладці Polygons / Cleanup / Groups |
| **📥 Імпорт** | ZIP або фото: «просто фото» (у будь-яких папках) або архів Mask Picker з розміткою. Після імпорту — обов'язкове вікно «Класи для цих фото»: впиши класи, які розмічатимеш (додаються до класів датасету) |
| **📤 Експорт** | Розмітка; галочки: «📷 Додати фото» (архів відкриється на будь-якому ПК), «Маски», «Фіналізувати», «Розбити на N» |
| **💾 Зберегти все** | Запекти контури у фінальні маски для всіх фото з 🟡 |

## Редактор — для всіх вкладок

| Клавіша / дія | Що робить |
|---|---|
| **Q** / **W**, **◀** / **▶** у шапці, **PageUp** / **PageDown** | Зберегти це фото й відкрити попереднє / наступне (та сама вкладка, той самий зум і положення камери). Натисни кілька разів швидко — перестрибне одразу на кілька фото, не чекаючи завантаження проміжних |
| **F** / кнопка **🎥 F** у шапці | Камера за курсором (увімк. / вимк.): при наближенні точка під курсором плавно їде до центру — зображення саме прокручується туди, куди ведеш мишку. Курсор біля центру — камера стоїть |
| **Tab** | Наступна вкладка: Cleanup → Polygons → Groups |
| **Ctrl+Z** | Скасувати (усі дії, включно з операціями над треками) |
| **Ctrl+Shift+Z** / **Ctrl+Y** | Повторити |
| Колесо миші | Наближення (до курсора) |
| **Пробіл**+тягнути, права / середня кнопка | Пересунути зображення |
| **0** | Масштаб 100% |
| **O** (тримати) | Показати оригінал без розмітки |
| **Esc** | Зняти виділення / скасувати дію; якщо нічого — зберегти й закрити редактор |
| **×** | Зберегти й закрити редактор |

## Вкладка Cleanup (чистка маски моделі)

| Клавіша / дія | Що робить |
|---|---|
| Клік по клітині | Викинути / повернути (інструмент Reject) |
| **R** / **M** | Інструмент Reject / Marker (📍 «тут треба дорозмітити») |
| **Enter** | Зберегти й закрити |

## Вкладка Polygons (малювання й правка контурів)

**Інструменти**

| Клавіша | Інструмент |
|---|---|
| **E** | Редагування (жоден інструмент не активний) |
| **D** | ✏️ Draw — малювати |
| **P** (або **G**) | 🎯 Pick — взяти контур: з тіні сусіднього фото або з клітини маски моделі |
| **B** | ✂ Розрив контуру |
| **1** … **9** | Клас для нових полігонів (nucleus, vesicle, …) |
| **S** | Seed all — усі контури з маски моделі (у ручному режимі вимкнено) |
| **Shift+S** | 🎯 Multi-seed — контури з масок моделей, по класах |

**Draw**

| Дія | Що робить |
|---|---|
| Клік | Поставити точку |
| **Shift** + вести мишкою | Точки ставляться самі (freehand) |
| **Enter** / подвійний клік | Замкнути полігон |
| **Backspace** | Прибрати останню точку |
| **Esc** | Скасувати недомальований полігон |

**Редагування (E)**

| Дія | Що робить |
|---|---|
| Тягнути точку | Пересунути точку |
| Тягнути всередині полігона | Пересунути весь полігон |
| Клік усередині полігона | Обрати полігон |
| Подвійний клік по лінії | Додати точку |
| **Alt**+клік по точці | Видалити точку |
| **Shift**+клік по точці | Додати / прибрати точку з виділення |
| Тягнути по порожньому місці | Ласо: обвести точки (**Shift** — додати, **Alt** — відняти) |
| Тягнути всередині пунктирної рамки | Пересунути вибрані ласо точки |
| **←↑→↓** (**Shift** — ×10) | Зсунути вибрані точки або обраний полігон на 1 (10) px |
| **Delete** | Видалити вибрані точки / обраний полігон |
| **📏 Align** | Вирівняти вибрані точки по лінії |
| **Enter** | Зберегти й закрити |

**✂ Розрив (B)** — переробити ділянку контуру

| Дія | Що робить |
|---|---|
| Клік по лінії / точці контуру | Розірвати тут (з'являються білі кінці) |
| Ще клік по лінії | Розірвати вдруге — коротший шматок червоний |
| **Shift**+клік по шматку | Обрати інший шматок |
| **Delete** / **🗑 Фрагмент** | Видалити обраний шматок |
| Клік по білому кінцю | Домальовувати від нього (жовтий) |
| Клік по другому кінцю | Замкнути контур |
| **Enter** / **✔ Замкнути** | З'єднати кінці прямою |
| **Backspace** | Прибрати останню домальовану точку |
| **Ctrl+Z** | Крок назад у розриві |
| **Esc** | Вийти з домальовування; ще раз — скасувати розрив |

**👻 Тінь сусідніх фото**

| Кнопка / дія | Що робить |
|---|---|
| **👻◀ Попереднє** / **Наступне ▶👻** | Показати полігони попереднього (рожеві) / наступного (зелені) фото |
| **P** + клік по тіні | Скопіювати полігон із тіні (той самий клас) |

**🎞 Треки** (та сама клітина на кадрах серії `назва_001`, `назва_002`…; кнопки видно для обраного полігона)

| Кнопка | Що робить |
|---|---|
| **🎞 Трек** | Зробити обраний полігон треком — продовжиться на наступних кадрах |
| **📎 До треку…** | Обраний полігон стає формою наявного треку на цьому кадрі (номер лишається, стара форма тут прибирається) |
| Змінити форму треку на кадрі | Цей кадр стає ключовим (`#3◆`), проміжні підлаштовуються |
| **⛔ Outside** | Клітина зникла з цього кадру (те саме, що видалити полігон треку тут) |
| **✂ Розділити** | Від цього кадру — новий номер |
| **🔗 Злити…** | Влити інший трек (номер) у цей |
| **🗑 Трек** | Прибрати трек з усіх кадрів |

## Вкладка Groups (групування клітин)

| Клавіша / дія | Що робить |
|---|---|
| **A** (або **L**) | ✎ Edit: клік по клітині — додати / прибрати з групи; тягнути — ласо |
| **G** | Group Picker: клік по клітині — обрати її групу |
| **N** | Нова група |
| **Delete** | Видалити поточну групу |
| **I** (тримати) | Підсвітити клітини поза групами |
| **Enter** | Зберегти |

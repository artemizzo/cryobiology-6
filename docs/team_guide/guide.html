Mask Picker

Інструкція для команди: як встановити програму для розмітки клітин і почати працювати.
Написано для тих, хто ніколи не працював з Docker, Git чи командним рядком — просто йди по кроках.

Що треба мати:

  • ноутбук / ПК з Windows 10 або 11;
  • 8 ГБ оперативної пам'яті або більше (на 4 ГБ працюватиме дуже повільно);
  • 15 ГБ вільного місця на диску C:;
  • інтернет (бажано не мобільний — завантажиться близько 2–3 ГБ);
  • близько 40–60 хвилин часу. Встановлення робиться один раз.

План: 1) перевірити ПК → 2) встановити Docker → 3) встановити Git → 4) завантажити програму → 5) створити ярлик і запустити → 6) працювати.

Що таке Docker і Git, у двох словах. Docker — це «коробка», в якій працює наша програма: усе потрібне вже всередині, нічого окремо (Python, бібліотеки) ставити не треба. Git — програма, яка завантажує наш проєкт з сайту GitHub і потім одним рядком його оновлює.

Крок 1. Перевірити ПК (2 хвилини)

1.1. Скільки пам'яті й який процесор

  1. Натисни Пуск → Параметри (шестерня) → Система → Про систему (в самому низу списку).
  2. Подивись рядки:
    • Встановлена ОЗП — має бути 8 ГБ або більше;
    • Тип системи — має бути «64-розрядна операційна система, процесор x64».

Якщо там написано «процесор на базі ARM» (буває на нових ноутбуках зі Snapdragon) — зупинись і напиши Артему, для такого ПК кроки трохи інші.

1.2. Чи увімкнена віртуалізація

Docker потребує функцію процесора, яка називається «віртуалізація». На більшості ПК вона вже увімкнена.

  1. Натисни разом Ctrl + Shift + Esc — відкриється Диспетчер завдань.
  2. Зліва (або вгорі) обери вкладку Продуктивність → ЦП (CPU).
  3. Внизу праворуч знайди рядок Віртуалізація (Virtualization).

Увімкнено (Enabled) — все добре, йди далі.

Вимкнено (Disabled) — її вмикають у BIOS ноутбука. Це не складно, але залежить від моделі: загугли «модель твого ноутбука enable virtualization BIOS» або попроси Артема допомогти. Без цього Docker не запуститься.

Крок 2. Встановити Docker Desktop (15–25 хвилин)

2.1. Завантажити

  1. Відкрий у браузері сайт: https://www.docker.com/products/docker-desktop/
  2. Натисни кнопку Download Docker Desktop і обери Download for Windows – AMD64 (саме AMD64, навіть якщо в тебе процесор Intel — це нормально).
  3. Завантажиться файл Docker Desktop Installer.exe (близько 500 МБ) — у папку «Завантаження».

2.2. Встановити

  1. Двічі клікни Docker Desktop Installer.exe.
  2. Windows спитає «Дозволити цій програмі вносити зміни?» — натисни Так.
  3. З'явиться вікно Configuration з галочками. Нічого не міняй, головне — щоб була відмічена Use WSL 2 instead of Hyper-V (recommended). Натисни OK.
  4. Чекай, поки йде встановлення (5–10 хв).
  5. Коли з'явиться кнопка Close and restart (або Close and log out) — збережи все, що відкрито, і натисни її. ПК перезавантажиться — це обов'язково.

2.3. Перший запуск Docker

Після перезавантаження Docker Desktop відкриється сам (якщо ні — знайди його в меню Пуск: набери «Docker»).

  1. Docker Subscription Service Agreement (угода) — натисни Accept. Для студентів і особистого використання Docker безкоштовний.
  2. Можуть спитати про налаштування — обирай Use recommended settings → Finish.
  3. Пропозиція увійти чи зареєструватися (Sign in / Sign up) — реєструватися не треба: натисни Skip або Continue without signing in.
  4. Опитування (survey) — теж Skip.
  5. Чекай, поки в лівому нижньому куті вікна Docker з'явиться зелене Engine running.

Назви кнопок у нових версіях Docker можуть трохи відрізнятися — зміст той самий: погодитись з угодою, пропустити реєстрацію, дочекатися «Engine running».

Якщо Docker пише, що треба оновити WSL («WSL needs updating», «WSL 2 installation is incomplete»):

  1. Натисни Пуск, набери PowerShell, натисни Enter.
  2. У синьому/чорному вікні надрукуй (або встав) команду і натисни Enter:
wsl --update

Дочекайся кінця, перезавантаж ПК і знову відкрий Docker Desktop.

Порада: у Docker Desktop натисни шестерню (Settings) вгорі → General → відміть Start Docker Desktop when you sign in to your computer → Apply. Тоді Docker вмикатиметься разом з Windows і програма стартуватиме швидше. (Не обов'язково.)

Крок 3. Встановити Git (5 хвилин)

  1. Відкрий сайт: https://git-scm.com/download/win
  2. Натисни Click here to download (або 64-bit Git for Windows Setup) — завантажиться файл на зразок Git-2.xx.x-64-bit.exe.
  3. Двічі клікни його → «Дозволити вносити зміни?» → Так.
  4. Буде багато вікон з налаштуваннями. Нічого не міняй — просто тисни Next у кожному.
  5. В останньому вікні — Install, чекай хвилину, потім Finish (галочку «View Release Notes» можна зняти).

Крок 4. Завантажити програму (3 хвилини)

4.1. Відкрити PowerShell

PowerShell — вікно, куди пишуть команди текстом. Нам треба лише кілька команд, їх можна копіювати звідси.

  1. Натисни Пуск, надрукуй PowerShell, натисни Enter.
  2. Відкриється вікно з текстом на зразок PS C:\Users\Ім'я> і миготливим курсором.

Як вставити команду: скопіюй її з цього PDF (Ctrl+C), клікни у вікно PowerShell і натисни Ctrl+V (або просто правий клік мишкою). Потім натисни Enter. Кожну команду — окремо, по черзі.

4.2. Виконати три команди

Перейти в папку «Документи»:

cd $HOME\Documents

Завантажити програму (з'явиться кілька рядків на зразок Cloning into 'cryobiology-6'... done):

git clone https://github.com/artemizzo/cryobiology-6.git

Відкрити папку програми у звичайному провіднику Windows:

explorer cryobiology-6

Якщо пише «git не розпізнано як ім'я командлету» (git is not recognized) — закрий вікно PowerShell, відкрий його знову і повтори команди. Не допомогло — перевстанови Git (крок 3).

Вікно PowerShell тепер можна закрити.

Крок 5. Створити ярлик і запустити (перший раз — 10–20 хвилин)

  1. У папці cryobiology-6, яка щойно відкрилась, знайди файл create_shortcuts (з шестернею на значку; повна назва — create_shortcuts.bat) і двічі клікни його.
  2. Відкриється чорне вікно з написом «Створено: …» — натисни будь-яку клавішу, щоб його закрити.
  3. На робочому столі з'явився ярлик Mask Picker. Двічі клікни його.
  4. З'явиться маленьке віконце зі статусом: «Перевіряю Docker…», «Запускаю / перевіряю оновлення…». Перший раз це довго — 10–20 хвилин: програма збирається і качає потрібне з інтернету. Не закривай віконце, не вимикай інтернет.
  5. Коли все готово, сам відкриється браузер зі сторінкою http://localhost:5000 — це і є програма.

Наступні запуски — секунди: просто двічі клікни ярлик Mask Picker. Якщо Docker не запущений, ярлик запустить його сам (тоді 1–2 хвилини).

Якщо відкрилось чорне вікно з купою тексту — це означає помилку, і в ньому написано причину. Зроби скріншот цього вікна (Win+Shift+S) і надішли Артему. Також можна надіслати файл cryobiology-6\_logs\launcher.log.

Крок 6. Як працювати

Перший раз

  1. Вгорі сторінки в полі «Хто розмічає» впиши своє ім'я.
  2. Кнопка 📥 Імпорт → обери фото (ZIP-архів або jpg/png) або архів з розміткою, який тобі надіслали.
  3. Список фото — зліва. Обери фото → картка «✋ Ручна розмітка» → відкриється редактор.
  4. Усі клавіші та кнопки — кнопка ? вгорі сторінки або клавіша ?.

Крок 7. Передати свою розмітку

  1. Кнопка 📤 Експорт → відміть фото, які хочеш передати.
  2. Якщо в отримувача цих фото ще нема — постав галочку «📷 Додати фото».
  3. Натисни Експортувати (поле «Зберегти у» лиши порожнім) — ZIP-архів скачається в папку «Завантаження», як звичайний файл з інтернету.
  4. Надішли цей ZIP (Telegram, Google Drive, пошта…).
  5. Отримувач у себе: 📥 Імпорт → обирає цей ZIP.

Одну серію кадрів (фото з назвами назва_001, назва_002…) краще розмічати одній людині: номери треків клітин з різних ПК не об'єднуються.

Крок 8. Оновити програму

Коли Артем скаже, що вийшла нова версія:

  1. Відкрий PowerShell (Пуск → PowerShell → Enter) і виконай по черзі:
cd $HOME\Documents\cryobiology-6 git pull
  1. Двічі клікни ярлик Mask Picker — він сам перезбере програму (1–3 хвилини).

Твоя розмітка в папці data при оновленні не змінюється.

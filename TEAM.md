# Mask Picker — як встановити й почати працювати

Інструкція для тих, хто розмічатиме клітини. Потрібен ПК з **Windows 10/11**.
Встановлення — один раз, ~30 хв (більшість часу — завантаження).

📄 **Детальна покрокова інструкція в PDF (для тих, хто ніколи не ставив Docker / Git):**
[`docs/Mask_Picker_Instrukciya.pdf`](docs/Mask_Picker_Instrukciya.pdf)

## 1. Встановити Docker Desktop
Docker — це «коробка», в якій працює програма (всередині вже є все потрібне, Python ставити не треба).

1. Завантаж: https://www.docker.com/products/docker-desktop/ → **Download for Windows**.
2. Запусти інсталятор, усі галочки лиши як є (**WSL 2** має бути ввімкнено).
3. **Перезавантаж ПК.**
4. Відкрий Docker Desktop. Вхід в акаунт можна пропустити (**Skip**). Внизу вікна має з'явитись
   «Engine running».

## 2. Встановити Git
Git потрібен, щоб завантажити програму й потім одним рядком її оновлювати.

1. Завантаж: https://git-scm.com/download/win → запусти інсталятор.
2. Усюди тисни **Next** (налаштування за замовчуванням підходять) → **Install**.

## 3. Завантажити програму
1. Відкрий **PowerShell** (Пуск → набери `PowerShell` → Enter).
2. Встав по черзі ці дві команди (кожну — Enter):
```bash
cd $HOME\Documents
```
```bash
git clone https://github.com/artemizzo/cryobiology-6.git
```
З'явиться папка `Документи\cryobiology-6` — це і є програма.

## 4. Створити ярлик і запустити
1. Відкрий папку `Документи\cryobiology-6` і двічі клікни **`create_shortcuts.bat`**.
   На робочому столі з'явиться ярлик **«Mask Picker»**.
2. Двічі клікни ярлик. **Перший запуск — до 10–15 хв** (програма збирається), далі — секунди.
   Потім сам відкриється браузер з програмою.
3. Якщо щось пішло не так — відкриється чорне вікно з текстом помилки. Зроби скріншот і надішли Артему
   (або файл `Документи\cryobiology-6\_logs\launcher.log`).

Порада: у Docker Desktop → **Settings → General** увімкни «Start Docker Desktop when you sign in» —
ярлик стартуватиме швидше.

## 5. Робота
- Угорі в полі **«Хто розмічає»** впиши своє ім'я.
- **📥 Імпорт** — додати фото (ZIP або окремі jpg/png) або архів з розміткою, який тобі надіслали.
- Як розмічати — `README.md`, розділ «✋ Ручна розмітка».
- Усі гарячі клавіші — кнопка **?** у програмі або файл [`docs/HOTKEYS.md`](docs/HOTKEYS.md).
- Закінчив — **💾 Зберегти все**. Вимкнути програму — закрити Docker Desktop
  (правий клік на значку кита біля годинника → **Quit Docker Desktop**).

**Де лежить твоя робота:** `Документи\cryobiology-6\data\` — фото й розмітка. Не видаляй цю папку
і не перейменовуй/не переноси папку `cryobiology-6` (якщо все ж переніс — запусти `create_shortcuts.bat` ще раз).

## 6. Передати розмітку іншим
1. **📤 Експорт** → постав галочку **«📷 Додати фото»**, якщо в отримувача цих фото ще нема → скачається ZIP.
2. Надішли ZIP (Telegram, Google Drive…).
3. Отримувач: **📥 Імпорт** → обрати цей ZIP.

Щоб поділити фото між кількома людьми — в експорті галочка **«Розбити на N»**: вийде N архівів (разом з фото),
вони з'являться в папці `Документи\cryobiology-6\data\vesicles_good\_split\`. Кожному — свій архів, він
імпортує його через **📥 Імпорт**.

## 7. Оновити програму
Коли Артем скаже, що вийшла нова версія:
1. PowerShell, по черзі:
```bash
cd $HOME\Documents\cryobiology-6
```
```bash
git pull
```
2. Запусти ярлик — він сам перезбере програму (хвилина-дві). Твоя розмітка в `data\` при оновленні не чіпається.

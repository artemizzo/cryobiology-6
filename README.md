# Cryobiology V — Cell Mask Annotation Pipeline

> Human-in-the-loop інструмент для побудови **ground-truth датасетів** сегментації
> клітинної мікроскопії: ML дає чорнові маски → людина у браузері їх відбирає,
> виправляє й групує → система запікає узгоджений датасет для аналізу.
>
> *Human-in-the-loop pipeline to turn rough ML cell-segmentation masks into a clean,
> grouped ground-truth dataset (instance + semantic masks + cell groups).*

**Версія 2.0.0** · Apache-2.0 · pytest **244/244** · Python 3.10+

```
 apps/segmentation  ─▶  data/<dataset>/output/  ─▶  apps/mask_picker  ─▶  deliverable
   (ML-моделі:           (чорнові instance-маски)    (Cleanup·Polygons·    (dense npy +
    Cellpose/InstanSeg/                               Groups + bake)        semantic + groups)
    YOLO)
```

---

## Що це
Сегментаційні моделі помиляються на складних знімках (пропуски, хибні обʼєкти, злиплі
клітини). Розмічати з нуля — дорого. Mask Picker бере **найкращий ML-вихід** і дає
анотатору швидко довести його до ідеалу та структурувати у клітини («1 ядро + N везикул»).

### Три інструменти в одному редакторі
- **Cleanup** — відхилити погані маски + позначити пропуски.
- **Polygons** — домалювати/виправити маски (draw / pick / seed-from-mask).
- **Groups** — обʼєднати інстанси у клітини, класифікувати за правилами.
- **✋ Ручна розмітка** — для будь-якого фото (навіть без масок моделей): малювати полігонами з нуля
  або взяти готові контури з масок моделей (Multi-seed). Інструмент **✂ Розрив** (B) — розірвати
  контур, прибрати неправильну ділянку, домалювати й замкнути. Деталі — `docs/architecture/16_MANUAL_MODE.md`.

### Особливості
- Робота з виходами **7 моделей** одночасно (відбір найкращої per-фото).
- Стабільні ID між запіканнями (reserved-range) → групи не «дрейфують».
- Глобальний хронологічний undo/redo на всі інструменти.
- Lazy-bake + автозбереження без гонок; фінальний deliverable у dense `1..N`.
- **244 автотести**, повна архітектурна документація, browser-верифіковані UI-фікси.

## ✋ Ручна розмітка — як користуватись

Для будь-якого фото, навіть якщо нейромережа не дала масок. Технічні деталі — [`docs/architecture/16_MANUAL_MODE.md`](docs/architecture/16_MANUAL_MODE.md).

**Додати фото.** Угорі **📥 Імпорт** → обрати ZIP з фото (у корені чи підпапках) або окремі jpg/png.
Фото потрапляють у `data/<датасет>/images/`; фото з таким самим іменем, що вже є, не перезаписується.
Архів, експортований самим Mask Picker (папки `images/ polygons/ selected/` + `selections.json`),
імпортується разом із розміткою, як і раніше. `.tif` — лише всередині ZIP.

**Розмітити.**
1. Обрати фото в списку → на картці **«✋ Ручна розмітка»** натиснути **☐** (стане ☑) → **✏️** — відкриється редактор полігонів.
2. Клас — кнопка з кольоровою крапкою або цифри **1–9**.
3. **✏️ Draw (D):** клік = точка, **Shift**+рух = точки самі; **Enter** / подвійний клік — замкнути;
   **Backspace** — прибрати точку; **Esc** — скасувати.
4. **Редагування (E):** тягнути точку; подвійний клік по лінії — додати точку; **Alt**+клік — видалити точку;
   клік усередині + **Delete** — видалити полігон. **Ctrl+Z / Ctrl+Shift+Z** — назад/вперед.
5. Готові контури з маски моделі (якщо вона є для цього фото): **🎯 Multi-seed (Shift+S)** → обрати модель
   для класу, галочка «Активно» → **Apply**. «📐 Seed all» у ручному режимі навмисно вимкнено.

**✂ Розрив (B) — переробити неправильну ділянку контуру.**
1. Клік по лінії контуру на початку поганої ділянки → розрив, з'являються **білі кола-кінці**
   (клік по точці контуру — розрив саме в ній).
2. Клік у кінці поганої ділянки → контур ділиться на 2 шматки, коротший — **червоний пунктир**
   (інший шматок обрати: **Shift**+клік).
3. **🗑 Фрагмент** / **Delete** — видалити червоний шматок.
4. Клік по білому колу → воно **жовте**, клікайте точки правильного контуру.
5. Клік по другому білому колу → контур замкнено. (**✔ Замкнути** / **Enter** — з'єднати кінці прямою;
   клік по кінцю іншого шматка — з'єднати шматки.)
6. **Ctrl+Z** — крок назад; **Esc** — вийти з домальовування, ще раз **Esc** — скасувати розрив (контур як був).

Працює з будь-яким полігоном: намальованим, імпортованим, узятим з маски моделі. Маску моделі саму
(растр) розірвати не можна — спершу перетворити на полігони (Multi-seed; у режимі моделі — Pick / Seed all).

**Зберегти.** **💾 Save Polygons** / **Enter** — контури збережено (автозбереження й так кожні ~5 с).
Позначка **«🟡 не запечено»** = контури змінились, а фінальна маска ще стара. **💾 Зберегти все** (угорі)
перетворює контури на маски («запікання») для всіх фото з жовтою крапкою.

### Як зберігається розмітка
Фото **не змінюється**; маска — окремий файл того ж розміру, де кожен піксель = номер клітини (0 — фон).

| Де (`data/<датасет>/…`) | Що |
|---|---|
| `images/` | оригінальні фото |
| `polygons/<фото>.json` | контури (LabelMe) — з них редактор відкриває розмітку для правок |
| `selected/manual/npy/` · `png/` | маска (ручні клітини мають номери 50000, 50001…) |
| `selected/manual/yolo/` | контури у форматі YOLO |
| `selected/manual/overlay/` | фото з намальованими контурами — лише для перегляду |
| `output/manual/` | службове: порожня «маска-основа» + копія фото (створює програма; не чіпати) |

Фінальний ZIP (**📤 Експорт** або `bake_all.py --pack`): `images/`, `masks/` + `masks_npy/` (клітини
перенумеровані 1…N), `semantic/` (1 = nucleus, 2 = vesicle), `overlays/`, `polygons/`, `yolo/`.

## Швидкий старт
Повна інструкція (встановлення, ваги, чистий ПК) → **[`INSTALL.md`](INSTALL.md)**.

> 🐳 **Без встановлення Python:** усе в Docker — `docker compose up --build` → http://localhost:5000. Деталі → **[`DOCKER.md`](DOCKER.md)**.

> **Windows:** спершу встанови [Microsoft Visual C++ Redistributable (x64)](https://aka.ms/vs/17/release/vc_redist.x64.exe) — без нього PyTorch не стартує (`OSError: WinError 126`, `c10.dll`).
```bash
pip install -r apps/mask_picker/requirements.txt
pip install -e ./shared/cellsegkit

# Крок 1 — ML-сегментація заповнює output/ (фото класти у data/my_dataset/images/).
# Перший запуск качає модель Cellpose-SAM ~1.2 ГБ → потрібен інтернет (деталі — INSTALL.md §3).
pip install cellpose                                           # + instanseg-torch / ultralytics за потреби
python apps/segmentation/run_segmentation.py --data-dir data/my_dataset

# Крок 2 — відбір і доразмітка у браузері:
python apps/mask_picker/app.py --workspace data/my_dataset    # → http://127.0.0.1:5000
```
Фінальний датасет: `python tools/launchers/bake_all.py --data-dir data/my_dataset --pack`.

## Дані та ваги моделей
Не зберігаються в репо (великі/чутливі), доступні окремо:
- **Розмічені датасети** (vesicles, nuclei): [Google Drive](https://drive.google.com/drive/folders/1jWNuxl-E7uaGRc3ubgug4RKz8cem_QTA).
- **Ваги моделей** (~1.8 ГБ): у **GitHub Releases** — завантажуються **автоматично** при першому
  запуску сегментації (`tools/download_weights.py`). Built-in моделі (cyto2/instanseg) ваг **із Release**
  не потребують, але cellpose 4.x при першому запуску сам качає свою модель **Cellpose-SAM (~1.2 ГБ)** —
  поради для повільної мережі/ВМ у [`INSTALL.md`](INSTALL.md) §3.
